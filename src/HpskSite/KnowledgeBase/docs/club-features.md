# Klubbsidor

Varje klubb på pistol.nu har sin egen sida med information, evenemang och mer.

## Hitta klubbar

Gå till **Klubbar** i menyn för att se alla klubbar. Klicka på en klubb för att öppna dess sida.

## Vad alla kan se (även utan inloggning)

- **Om Klubben** — beskrivning och bakgrund
- **Kontaktinformation** — kontaktperson, e-post, telefon, adress, hemsida
- **Dokument** — offentliga snabblänksdokument (om klubben har konfigurerat sådana)

## Vad inloggade medlemmar ser

Utöver ovanstående får du flikar:

### Hem
- **Kommande Händelser** — alla kommande evenemang (träning, möten, socialt m.m.) och nyheter
- **Sidopanel:**
  - **Utvalda Tävlingar** — tävlingar och serier som klubben valt att lyfta fram
  - **Kontakt** — kontaktinformation
  - **Snabblänkar** — genvägar till Kalender, Medlemmar, Tävlingar och utvalda dokument

### Om Klubben
Klubbens fullständiga beskrivning och bakgrund.

### Kalender
Månadsvis vy över klubbens evenemang. Typer av evenemang:
- Träning
- Städning
- Möte
- Socialt
- Nyhet
- Annat

(Tävlingar skapas separat via tävlingshanteringen, inte som vanliga evenemang.)

Klicka på ett evenemang för att se detaljer: namn, datum/tid, beskrivning, plats och kontaktperson.

### Medlemmar
Lista över klubbens medlemmar med:
- Namn och profilbild
- E-postadress (på desktop)
- Knapp för att se medlemmens dashboard (om de delat den)

### Dokument
Klubbens delade dokument — regler, scheman, blanketter m.m. Här kan du ladda ner filer.
