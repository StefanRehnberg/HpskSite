# Min Sida

Min Sida är din personliga sida där du ser all din statistik, registrerar resultat och hanterar dina inställningar. Du hittar den via användarmenyn.

## Flikar

### Dashboard

Översikt med fyra informationskort:

1. **Aktivitet** — totalt antal pass, fördelning per vapenklass, uppdelning träning/tävling
2. **Aktuell Form** — snittscore senaste 30 dagarna med trendindikator i procent
3. **Standardmedaljer** — antal silver- och bronsmedaljer samt poäng
4. **Personliga Rekord** — bästa resultat per vapenklass

Under korten visas **diagram**:
- Poängutveckling över tid (linjediagram)
- Vapenklassjämförelse (stapeldiagram)

Diagrammen har filter för **disciplin** (Precision, Milsnabb, Duell, Nationell Helmatch, Magnum Precision) och **år**.

#### Dela din Dashboard

Via **"Dela min Dashboard"** kan du ställa in vem som kan se din dashboard:
- **Klubbkamrater** — medlemmar i din klubb
- **Alla medlemmar**
- **Ingen (privat)**

### Resultat

Alla dina registrerade träningsresultat.

**Filter:**
- **Disciplin** — Precision, Milsnabb, Duell, Nationell Helmatch, Magnum Precision
- **År**
- **Vapenklass** — Alla, A, A Opt, B, C, R, M, L

**Tabellen visar:** Datum, Typ (träning/tävling/officiell), Klass (vapenklass), Poäng (total + snitt per serie), X-antal, Tävling (namn eller streck).

Du kan redigera eller ta bort resultat du själv lagt in.

#### Lägga in träningsresultat

Klicka **"Lägg in Resultat"** på Resultat-fliken.

1. Välj:
   - **Datum** (kalender)
   - **Vapenklass**
   - **Disciplin**
   - **Beskrivning** (obligatoriskt, t.ex. "Morgonträning")
2. Välj inmatningsmetod:
   - **Detaljerad (skott-för-skott)** — rekommenderas. Tryck på knappar (X, 10, 9, 8... ner till 0) för varje skott. Navigera mellan serier.
   - **Serie-totaler** — skriv in totalen för varje serie
   - **Bara totalt** — skriv in enbart totalpoängen
3. Valfritt: kryssa i **"Detta är ett resultat från en tävling"** för att lägga till tävlingsklass, placering och eventuell standardmedalj (dessa fält är frivilliga)
4. Klicka **"Spara"**

Resultaten syns direkt i din statistik, dina diagram och din handikappberäkning.

### Tävlingar

Se alla tävlingar du är anmäld till. Filtrera på år, status, betalning och fritext. Här kan du:
- Se betalningsstatus
- Betala obetalda avgifter via Swish
- Avanmäla dig (om tillåtet)

### Handikapp

Inställningar per disciplin. För varje disciplin (Precision, Milsnabb, Duell, Nationell Helmatch, Magnum Precision):

1. **Skytteklass** — välj din klass:
   - Klass 1: Nybörjare
   - Klass 2: Guldmärkesskytt
   - Klass 3: Riksmästare
2. **Handikappindex** — visas automatiskt baserat på dina resultat. Klicka **"Omberäkna"** för att uppdatera.

Skytteklassen sparas automatiskt när du ändrar den.
