# Skjutledare

Som skjutledare på en klubb har du utökade rättigheter för träning och resultatrapportering.

## Godkänna steg i Skyttetrappan

Du kan godkänna steg för alla medlemmar i din klubb — inte bara de i en specifik träningsgrupp.

1. Gå till **Skyttetrappan** > fliken **"Administration"**
2. Sök eller välj den medlem vars steg ska godkännas
3. Klicka **"Godkänn"** på aktuellt steg
4. Lägg till en eventuell anteckning

## Träningsgrupper

Via **Skyttetrappan** > fliken **"Administration"** kan du:
- Se alla aktiva träningsgrupper på din klubb
- Skapa nya träningsgrupper
- Redigera grupper — lägga till/ta bort medlemmar och tränare
- Avaktivera grupper
- Se medlemmars framsteg

## Rapportera resultat

Om en tävling har **distribuerad resultatrapportering** aktiverad kan du rapportera resultat via knappen **"Rapportera resultat"** på tävlingssidan.

**Obs:** Du har inte tillgång till den fullständiga tävlingshanteringssidan (startlistor, klasssammanslagning m.m.) — för det krävs att du är tilldelad som tävlingsledare, klubbadmin eller sajtadmin.

## Vad skjutledare INTE kan göra

- Godkänna nya medlemmar (kräver klubbadmin, kretsadmin eller sajtadmin)
- Komma åt klubbens Admin-panel (kräver klubbadmin)
- Hantera tävlingar fullt ut (kräver tävlingsledare eller klubbadmin)
