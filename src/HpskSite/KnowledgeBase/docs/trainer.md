# Tränare i Skyttetrappan

Som tränare i en träningsgrupp kan du följa dina medlemmars framsteg och godkänna steg i Skyttetrappan.

## Dina träningsgrupper

Gå till **Skyttetrappan** och klicka på fliken **"Min Träningsgrupp"**. Här ser du:
- Alla medlemmar i din grupp
- Varje medlems nuvarande nivå och steg
- Knappen **"Visa framsteg"** för varje medlem

## Godkänna steg

När en medlem har uppnått målet för ett steg:
1. Klicka på **"Visa framsteg"** för medlemmen
2. Hitta steget som ska godkännas
3. Klicka **"Godkänn"**
4. Valfritt: lägg till en anteckning
5. Steget markeras som avklarat och nästa steg öppnas för medlemmen

Medlemmen får ett e-postmeddelande med bekräftelse.

**Obs:** Du kan bara godkänna steg för medlemmar i din **aktiva** träningsgrupp. Om gruppen avaktiveras förlorar du godkännanderätten — då kan skjutledare eller klubbadmin godkänna istället.

Andra roller som också kan godkänna steg: skjutledare (för hela klubben), klubbadmin (för hela klubben) och sajtadmin (för alla).

## Följa framsteg

Du kan se:
- Vilka steg varje medlem har klarat
- Datum för varje godkännande
- Vilken nivå medlemmen befinner sig på
- Eventuella anteckningar från tidigare godkännanden

## Gruppmeddelanden

Du kan skicka meddelanden till alla i din träningsgrupp för att kommunicera träningsscheman, tips eller annan information.
